# 个人学术主页维护指南

本网站由 GitHub Pages 自动发布。每次在 GitHub 仓库保存修改后，通常等待 1–3 分钟，刷新主页即可看到更新。

## 一、上传老师照片

1. 打开仓库：`kun-yu55/teacher-homepage`。
2. 打开 `images` 文件夹，点击 **Add file → Upload files**。
3. 上传一张清晰的正方形或接近正方形照片，文件名请统一为 `profile.jpg`。
4. 点击 **Commit changes** 保存。
5. 打开根目录的 `_config.yml`，点击右上角铅笔图标编辑，把这一行：

   ```yml
   avatar           :
   ```

   改为：

   ```yml
   avatar           : "images/profile.jpg"
   ```

6. 点击 **Commit changes**。主页顶部的“老师照片”预留位会自动替换为照片。

建议：使用 JPG 或 PNG 格式，边长至少 600 像素；不要使用带敏感个人信息的证件照。

## 二、修改老师基本信息

打开根目录的 `_config.yml`，在 `author:` 下修改：

- `name`：姓名
- `bio`：职称、导师身份
- `location`：城市
- `employer`：学院/单位
- `email`：联系邮箱
- `avatar`：头像文件路径

顶部信息栏会自动读取这些字段。

## 三、修改主页正文

打开 `_pages/about.md`。这是主页的主要内容文件，可修改：

- 个人简介
- 研究方向
- 代表性论文
- 科研项目
- 授权专利
- 学生培养与招生信息

正文采用 Markdown 格式。普通文字直接改即可；论文链接写法如下：

```md
[论文代码](https://github.com/用户名/仓库名)
```

列表项以 `- ` 或 `1. ` 开头。请保留类似 `<span class='anchor' id='research'></span>` 的锚点行，否则顶部导航无法定位到相应栏目。

## 四、修改顶部导航

打开 `_data/navigation.yml`。每个栏目包含：

- `title`：导航显示的文字
- `url`：对应正文锚点

新增栏目时，先在 `_pages/about.md` 中添加同名 `id` 的锚点，再在导航文件中添加链接。

## 五、修改颜色与页面布局

打开 `assets/css/main.scss`。页面主色、文字颜色、顶部信息卡、照片框等样式均在文件末尾的 `Single-column academic profile layout` 部分。若只改内容，请不要修改该文件。

## 六、查看发布结果

永久主页地址：

`https://kun-yu55.github.io/teacher-homepage/`

若更新后暂未显示，请等待几分钟后按 `Ctrl + F5` 强制刷新。不要删除 `Gemfile`、`_layouts` 或 `_includes` 中的文件，以免影响发布。
