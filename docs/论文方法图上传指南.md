# 论文方法图上传指南

每张论文卡片会自动读取 `images/publications/` 文件夹中对应的 PNG 图片。图片不存在时，主页保留“方法示意图 / 待上传”图位；上传后会自动显示，无需修改网页代码。

## 上传步骤

1. 打开仓库中的 `images` 文件夹，依次进入 `publications` 文件夹。
2. 点击 **Add file → Upload files**。
3. 上传 PNG 图片；文件名必须与下表完全一致。
4. 点击 **Commit changes**。等待 GitHub Pages 发布约 1–3 分钟后刷新主页。

建议使用横向 PNG，比例约 16:9 或 4:3，宽度至少 1000 像素。图片应为论文的方法总览图，不建议使用论文首页截图。
